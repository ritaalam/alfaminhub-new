name: Studio visual contracts
description: How visual refreshes stay compatible with explicit worksheet page contracts.
---

For a page with an explicit teacher-authored interaction, Change visuals may change illustration direction but must not replace countable assets when that replacement can widen or contradict the named subject.

**Why:** A broad theme asset pool can turn a coherent counted set into a mixed scene, making the instruction semantically false even when object totals and answer keys remain correct.

**How to apply:** Preserve the printable content and response mechanics for explicit pages, and make the visible style change through the page illustration direction. Flexible, unconstrained pages may still rotate compatible assets after validation.
