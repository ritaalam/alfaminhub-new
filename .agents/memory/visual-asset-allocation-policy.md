---
name: Visual asset allocation policy
description: Preserve teacher-named visual content while adapting open-ended theme pools to the learner's age and activity.
---

Explicit objects named in a teacher's request must remain in the worksheet asset plan, even when their default visual complexity would normally be above the selected age band's open-pool threshold. Age suitability and diversity rules apply only when the teacher asked for a theme or category rather than specific pictured objects.

**Why:** Substituting a named object silently changes the requested learning content, while filtering an open theme pool is a safe way to reduce visual complexity for younger learners.

**How to apply:** Keep requested and required assets locked through planning, Studio edits, persistence, and print. Apply age/mechanic eligibility, exclusions, and deterministic rotation only to non-explicit candidates. Use a local, explicit fallback rather than remote image search.
