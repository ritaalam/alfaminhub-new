---
name: Studio differentiation
description: Pedagogical rules for Make harder and Make easier in Worksheet Studio.
---

Studio difficulty controls must alter the printable learning task itself while retaining the teacher-selected topic, activity mechanic, and level wherever possible. For Memory Pairs, differentiate with the number of vocabulary pairs and the availability of word-label support.

**Why:** Changing only copy or presentation gives the teacher no different worksheet, while replacing the mechanic breaks the activity contract they selected.

**How to apply:** Harder versions should increase meaningful workload and reduce supports; easier versions should reduce workload and restore appropriate supports. Both directions must still pass the same validation gate used before Studio and PDF export.
